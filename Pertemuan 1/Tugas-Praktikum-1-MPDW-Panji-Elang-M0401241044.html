Menentukan Nilai m

nilai_m <- c(3, 4, 5, 7, 10, 20)

hasil_sma <- data.frame(
  m = nilai_m,
  SSE = NA,
  MSE = NA,
  RMSE = NA,
  MAPE = NA
)

for (i in 1:length(nilai_m)) {
  
  m <- nilai_m[i]
  
  # Menghitung SMA pada data latih
  data.sma <- SMA(training$harga_close, n = m)
  
  # Mengambil nilai SMA terakhir
  nilai_terakhir <- tail(na.omit(data.sma), 1)
  
  # Forecast untuk seluruh data uji
  ramalan <- rep(nilai_terakhir, n_test)
  
  # Error
  error <- testing$harga_close - ramalan
  
  # SSE
  SSE <- sum(error^2)
  
  # MSE
  MSE <- mean(error^2)
  
  # RMSE
  RMSE <- sqrt(MSE)
  
  # MAPE
  MAPE <- mean(abs(error / testing$harga_close)) * 100
  
  # Masukkan hasil
  hasil_sma[i, "SSE"] <- SSE
  hasil_sma[i, "MSE"] <- MSE
  hasil_sma[i, "RMSE"] <- RMSE
  hasil_sma[i, "MAPE"] <- MAPE
}

Sesuai sifat dasar SMA, nilai ramalan untuk seluruh periode data uji bernilai konstan datar pada angka 7.371,25, yang mengakibatkan terjadinya under-forecasting karena harga aktual pada data uji terus mengalami tren kenaikan hingga menyentuh angka 8.050 sehingga metode pemulusan tunggal ini belum mampu menyesuaikan arah tren secara otomatis.

Hasil evaluasi peramalan Single Moving Average (SMA) dengan orde m=20 menunjukkan kinerja model yang sangat akurat, baik pada tahap pembentukan model (data latih) maupun pada pengujian performa sesungguhnya (data uji). Pada data latih, model mencatatkan nilai RMSE sebesar 233,93 dengan tingkat kesalahan rata-rata (MAPE) sebesar 2,57%, yang menandakan bahwa pemulusan rata-rata bergerak 20 harian mampu mengikuti pola pergerakan harga historis dengan amat baik. Ketika diuji pada data uji yang tidak dilatih sebelumnya, nilai kesalahan mengalami sedikit peningkatan menjadi RMSE sebesar 394,34 dan MAPE sebesar 4,34%, yang merupakan hal wajar karena peramalan SMA bersifat konstan datar (flat forecast) ke masa depan. Meski demikian, karena nilai MAPE pada data uji berada jauh di bawah rentang 10%, dapat disimpulkan bahwa kemampuan generalisasi model SMA m=20 ini masuk ke dalam kategori peramalan sangat baik (highly accurate) dan layak digunakan sebagai baseline pemulusan.
